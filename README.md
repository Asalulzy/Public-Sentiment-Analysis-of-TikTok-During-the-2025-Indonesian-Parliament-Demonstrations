# Public Sentiment Analysis of TikTok During the 2025 Indonesian Parliament Demonstrations

## Overview

This project was conducted as part of a Text Analysis course and focuses on understanding Indonesian public sentiment toward TikTok during the 2025 Indonesian Parliament demonstrations.

The study analyzed more than 21,000 Indonesian-language user comments to identify sentiment trends, emerging topics, and changes in public perception toward the platform during a significant national event.

## My Role

**NLP Developer & Machine Learning Engineer**

I was responsible for data preparation, validation, sentiment analysis, and interpretation of the findings.

## Problem Statement

Public sentiment on social media can rapidly change during major political and social events. Understanding these changes is important for identifying public concerns, trust issues, and platform perception.

## Dataset

* 21,000+ Indonesian-language comments
* User-generated content collected from TikTok discussions related to the 2025 Indonesian Parliament demonstrations

## Data Preparation

The project included:

* Data cleaning
* Text normalization
* Noise removal
* Annotation preparation
* Consistency checking
* Data validation

Special attention was given to ensuring data quality before analysis.

## Methodology

### Text Preprocessing

* Case folding
* Tokenization
* Stopword removal
* Text normalization

### Analysis

* Sentiment classification
* Topic exploration
* Trend analysis

### Validation

* Consistency checking
* Dataset quality assessment

## Key Findings

The analysis identified:

* Significant shifts in public sentiment during the event period.
* Emerging discussion themes related to trust and platform perception.
* Approximately four times higher negative sentiment compared with historical observations since 2023.
